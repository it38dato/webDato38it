# Web-Portfolio & Backend Platform

![Django CI](https://github.com)

Бэкенд-платформа и сайт-портфолио на **Python/Django**, созданные для демонстрации моих проектов, навыков разработки коммерческих веб-приложений и предоставления IT-услуг. 

Проект представляет собой полноценный production-ready стек с REST API, контейнеризацией, автоматизированными скриптами управления и интеграцией с чат-ботом.

---

## 🎯 Цель проекта и коммерческое применение
Проект развивается как моя персональная витрина и технологическая база. В будущем на этой платформе будут развернуты:
*   **Портфолио выполненных проектов** с интерактивным описанием кейсов.
*   **Модуль заказа услуг** (бэкенд-разработка, автоматизация, создание ботов) с интеграцией через API.
*   **Собственные SaaS-микросервисы** и внешние бизнес-интеграции.

---

## 🛠 Технологический стек

*   **Бэкенд:** Python 3, Django, Django REST Framework (DRF), JWT (аутентификация).
*   **База данных:** PostgreSQL.
*   **Инфраструктура & DevOps:** Docker, Docker Compose, Nginx, Gunicorn.
*   **Тестирование:** Django Test Framework, APIClient, pytest.
*   **CI/CD:** GitHub Actions (на стадии тестирования и отладки).

---

## 🤖 Интеграция с MAX Bot
В проект интегрирован кастомный бот **MAX Bot**, который дублирует ключевую информацию из бэкенда Django и обеспечивает оперативное взаимодействие с платформой.

Бот реализован в виде кастомной management-команды Django.

## 🚀 Инструкция по запуску

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd webDato38it
```

### 2. Запуск инфраструктуры в Docker
Соберите и запустите контейнеры (Django, PostgreSQL, Nginx) в фоновом режиме:
```bash
docker compose up --build -d
```

### 3. Миграции и создание Администратора
```bash
# Применить миграции базы данных
docker compose exec web python manage.py migrate

# Создать суперпользователя для панели управления
docker compose exec web python manage.py createsuperuser
```

### 4. Запуск MAX Bot
Запуск бота выполняется внутри контейнера веб-приложения одной командой:
```bash
docker compose exec web python manage.py max_bot
```

### Доступные URL-адреса (локально):
*   Главная страница/API: `http://localhost:8000`
*   Панель администратора Django: `http://localhost:8000/admin`
*   Интерактивная Swagger-документация API: `http://localhost:8000/api/docs`

## 🧪 Тестирование и автоматизация (CI/CD)

В проекте реализовано автоматическое тестирование REST API с использованием `APIClient` и встроенного Django Test Framework. 

### Локальный запуск тестов:
```bash
docker compose exec web python manage.py test
```

### Непрерывная интеграция (CI/CD):
Платформа полностью интегрирована с **GitHub Actions**. Воркфлоу настроен в файле `.github/workflows/django.yml`. 
При каждом `push` или `pull_request` в ветки `main`/`master` автоматически запускается пайплайн, который:
1. Разворачивает изолированное окружение на базе `ubuntu-latest`.
2. Поднимает временную тестовую базу данных **PostgreSQL 15** через GitHub Services.
3. Устанавливает зависимости проекта и проверяет корректность работы бэкенда, запуская тестовое покрытие.
